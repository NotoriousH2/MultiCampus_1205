# Sora 2 영상 생성기

OpenAI Sora 2 API를 활용한 AI 영상 생성 Streamlit 애플리케이션입니다.

## 주요 기능

- **텍스트로 영상 만들기**: 프롬프트만으로 AI 영상 생성
- **이미지로 영상 만들기**: 이미지를 첫 프레임으로 사용하여 영상 생성
- **자동 이미지 변환**: 업로드한 이미지를 선택한 해상도에 맞게 자동 리사이즈
- **실시간 진행률 표시**: 영상 생성 진행 상황을 실시간으로 확인
- **완료 알림**: 영상 생성 완료 시 알림
- **다운로드**: 생성된 영상을 MP4로 다운로드
- **API 키 저장**: 입력한 API 키를 로컬에 저장하여 재사용

## 설치 방법

### 1. 저장소 클론

```bash
git clone <repository-url>
cd sora-video-generator
```

### 2. 가상 환경 생성 (권장)

```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
```

### 3. 의존성 설치

```bash
pip install -r requirements.txt
```

## 실행 방법

```bash
streamlit run app.py
```

브라우저에서 `http://localhost:8501`로 접속합니다.

## 사용 방법

### 1. API 키 설정

1. 사이드바에서 OpenAI API 키 입력
2. "저장" 버튼 클릭하여 키 저장 (다음 접속 시 자동 로드)

### 2. 모델 설정

| 설정 | 옵션 | 설명 |
|------|------|------|
| 모델 | Sora 2 | 빠른 생성, 반복 작업에 적합 |
|  | Sora 2 Pro | 고품질 출력, 프로덕션용 |
| 해상도 | 480p / 720p / 1080p | 높을수록 생성 시간 증가 |
| 길이 | 4초 / 8초 / 12초 | 영상 길이 |

### 3. 영상 생성

#### 텍스트로 영상 만들기
1. "텍스트로 영상 만들기" 탭 선택
2. 프롬프트 입력 (촬영 유형, 피사체, 동작, 배경, 조명 설명)
3. "생성하기" 클릭

#### 이미지로 영상 만들기
1. "이미지로 영상 만들기" 탭 선택
2. 이미지 업로드 (자동으로 해상도에 맞게 변환됨)
3. 동작 프롬프트 입력
4. "생성하기" 클릭

### 4. 결과 확인

- 진행률 표시줄로 생성 상황 확인
- 완료 시 영상 플레이어에서 미리보기
- "MP4 다운로드" 버튼으로 저장

## 프롬프트 작성 팁

효과적인 프롬프트를 위해 다음을 포함하세요:

- **촬영 유형**: Wide shot, Close-up, Aerial drone shot 등
- **피사체**: 무엇을/누구를 촬영할지
- **동작**: 어떤 움직임이 있는지
- **배경**: 장소, 환경
- **조명**: Golden hour, Night, Soft light 등

### 예시 프롬프트

```
일출 시 안개 낀 산맥 위를 날아가는 에어리얼 드론 샷, 구름 사이로 스며드는 황금빛

밤의 분주한 도시 교차로 타임랩스, 젖은 도로에 반사되는 네온 불빛

나무 테이블 위 김이 나는 커피 컵 클로즈업, 블라인드 사이로 들어오는 아침 빛
```

## 주의사항

- **콘텐츠 제한**: 18세 이상 콘텐츠, 저작권 캐릭터/음악, 실제 인물 생성 불가
- **얼굴 제한**: 사람 얼굴이 포함된 이미지는 거부될 수 있음
- **다운로드 기한**: 생성된 영상 URL은 1시간 후 만료
